# Correction: status of the statements in this repository

**Date of correction:** 30 October 2026 · **Issued by:** Gravit Open Network Foundation

This repository dates from April 2026, before the public Gravit Verifier existed. The original texts are kept unchanged below this note and in `paper/`, because history is not rewritten. Read them with these corrections:

1. **xAI is not a partner.** xAI has not reviewed, endorsed or taken part in this work. "Grok" names the model this proof of concept calls through xAI's public API, nothing more. The author line "Grok (xAI) Integration Team" in `paper/main.tex` does not refer to people at xAI. During the work, the Grok chatbot presented several named "agents" and described a team, departments and roles; these were personas generated by the chatbot itself. No person from xAI took part, and the foundation understood this at the time.
2. **"Official"** in the README means only that this is the foundation's own repository.
3. **The "five live integration tests"** described in `paper/main.tex` have no logs, data or code in this repository that would let anyone reproduce them. Treat them as unverified.
4. **"Immutable" and "adversarially-robust"** are design goals of this early prototype, not tested properties.

The current, reproducible work is the public [Gravit Verifier](https://github.com/gravit-open-network-foundation/verifier) (v0.7.0, 54 golden vectors, Python and Rust agree) and the hosted API at [gravitverifier.space](https://gravitverifier.space). A rebuild of this proof of concept on that verifier, for any LLM including Grok, is planned.
